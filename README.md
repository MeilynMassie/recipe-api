# Recipe API

## Description

A Spring Boot REST API for managing recipes and communicating with the Recipe AI Service to extract recipe information from uploaded images. Recipes are stored in PostgreSQL and can be created, viewed, edited, and deleted.

AI Service: recipe-ai-service

- **Core Features:**
  - Create recipes
  - View recipes
  - Edit recipes
  - Delete recipes
  - Upload recipe image for AI extraction
  - Communicate with Recipe AI Service
  - Validate recipe data
  - Store recipes in PostgreSQL

- **Later Me Problem:**
  - User accounts & authentication
  - Recipe search/filtering
  - Recipe categories/tags
  - Favorites
  - Image storage
  - Advanced error handling

- **Languages/Tools Used:**
  - Java
  - Spring Boot
  - Spring Data JPA
  - PostgreSQL
  - Flyway
  - REST API
  - Docker
  - React/TypeScript
